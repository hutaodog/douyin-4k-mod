## 二、安卓的画质机制（逆向结论）

### 2.1 全局设置只有 3 档，没有 4K

`com.ss.android.ugc.aweme.setting.ui.SettingVideoQualityActivity`（`classes33.dex`）：

```java
Keva.getRepo("video_quality_keva").storeInt("video_quality_type", k);   // k ∈ {1,2,3}
ISimKitService.CC.get().setBitrateQuality(k);
if (isWifi() && k == 3) setBitrateQuality(1);
```

资源表里的三句文案：`画质调节已切换至智能模式 / 省流模式 / 高清模式`。
→ **UI 上限就是"高清模式"，没有 4K 选项。**

### 2.2 但 4K 挡位在客户端内部存在

`X.0FWR`（`classes2.dex`，手动清晰度枚举）：

```java
Manual_Extremly_High_Dolby(11, "2160_dolby")
Manual_Extremely_High_HDR(10, "2160p_hdr")
Manual_Extremely_High    ( 9, "2160p")      ← 4K = 9
Manual_Super_High        ( 7, "1440p")
Manual_High              ( 5, "1080p")
Manual_Auto              ( 0, "auto")
```

播放器入口：

```java
// com.ss.android.ugc.aweme.simkit.SimKitService
public final void setBitrateQuality(int i) {
    C0FZ3.LIZ = i;
    TTVideoEngine.LIZ(1006, i);      // setIntOption(1006, ...)

```

### 2.3 同样的"自动降档"体系也在

`com.ss.android.ugc.playerkit.exp.PlayerSettingCenter`（`classes2.dex`）：


以及播放器内核（`classes54.dex`）的 `abr_config / abr_strategy / abr_switch / abr_switch_stall_time / abr_switch_count` 等一整套。

## 三、四个版本的实测结果

| 版本 | 做法 | 结果 |
|---|---|---|
| v1–v2 | 只改名（全局字节替换 manifest） | 装不上：`INSTALL_FAILED_CONFLICTING_PROVIDER`（3 个不带包名前缀的 authority 撞车） |
| v3 | 改名 + 修 3 个 authority | **装上但启动闪退**：`ClassNotFoundException …AwemeHostApplication`（类名被一起改掉） |
| v4 | 精确改包名（只改 package/authority/权限）+ 画质补丁 | ✅ 装上、启动、**未登录可正常刷视频**；❌ 登录验证码后「当前版本过低」 |
| v5 | **不改包名**（官方 `com.ss.android.ugc.aweme`）+ 只打画质补丁 | ✅ 装上、启动、进推荐页正常播放；❌ 登录仍「当前版本过低」 |

> v4 需要先卸载占用了 `com.ss.android.ugc.aweme.gkfs` 的旧包才能装 v5。
> v5 与官方包名相同，**不能共存**，装前必须卸载官方抖音。

## 四、为什么登录一定失败

1. 应用自身日志在 release 版被剥离，logcat 看不到接口返回，只能从行为判断；
2. 登录时客户端上报 `metasec` 生成的设备/客户端指纹（`X-Argus`、`msToken` 等）；
3. 包名相同但**签名不同**（我们用自己的 debug key 重签）→ 服务端认为"这不是已知客户端版本"→ 判「版本过低」；
4. 该判定**在服务端**，客户端改代码绕不过；伪造整套指纹属于和风控正面冲突，且会随服务端策略失效。

## 五、如果以后还要做安卓

**唯一正路：保持官方 APK 不变（登录/风控全正常），用 root + LSPosed 模块或 Frida 脚本在运行时 hook。**

建议 hook 点（已定位）：

| 目标 | 说明 |
|---|---|
| `com.ss.android.ugc.aweme.simkit.ISimKitService.setBitrateQuality(int)` | 全局质量模式入口 |
| `com.ss.android.ugc.playerkit.exp.PlayerSettingCenter` 的 `G4()` / `abr_work_with_manual_resolution` | 关掉"手选后自动调整" |
| `X.0FWR`（手动清晰度枚举） | 强制 `Manual_Extremely_High(9, "2160p")` |

前提：K40 需要解 BL 锁 + Magisk（会清数据）。
