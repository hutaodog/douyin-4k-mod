# 19-画质档位对照表（65 条视频实测）

> 目的：把抖音的"档位名"和"实际画质"对应起来，搞清楚每个档位到底是什么，
> 以及不同视频能给的最高画质分布。
>
> 采集方式：网页接口（带登录 cookie），从一条种子视频出发用 `related` 接口逐层扩展，
> 抓取每条视频的完整 `video.bit_rate[]`。
> 工具：`mobile-web/tools/probe-gears-bfs.mjs` + `analyze-gear-tiers.mjs`
> 原始数据：`mobile-web/probe-output/gears-collection.json`

---

## 一、样本概况

| 项 | 数值 |
|---|---|
| 视频数 | **65 条** |
| 每条视频档位数 | 平均 **13.7** 档（最少 7，最多 24） |
| 画幅 | 横屏 62 / 竖屏 3 |
| 出现过的档位名 | **23 种** |

⚠️ 一个容易踩的坑：**竖屏视频的 `height` 是长边**（1080×1920 的 1080P 视频 `height=1920`）。
判断画质必须用 `min(宽,高)`，否则会把竖屏 1080P 误判成 2K。

### 命名规律（从数据里反推）

```
adapt_lowest_<短边>_<变体>   ← 自适应档位（"lowest"指该分辨率下的最低码率版本）
normal_<短边>_<变体>         ← 标准档位
low_<短边>_<变体>            ← 低码率版
lower_<短边>_<变体>          ← 更低码率版
<短边>_<编码族>_<序号>       ← 客户端侧命名（如 720_2_1：720p / 编码族2 / 第1种）
```

**关键结论：4K 和 2K 只有 h265**；1080P 及以下 h264/h265 都有。

## 三、每条视频"能给的最高画质"分布

| 最高画质 | 条数 | 占比 |
|---|---|---|
| **4K** | 13 | **20.0%** |
| **2K** | 29 | **44.6%** |
| **1080P** | 21 | 32.3% |
| 720P | 1 | 1.5% |
| 540P | 1 | 1.5% |

各档位的**覆盖率**（有多少条视频提供这一档）：

| 档位 | 提供该档的视频 |
|---|---|
| 4K | 13 / 65（**20%**） |
| 2K | 42 / 65（**65%**） |
| 1080P | 63 / 65（97%） |
| 720P | 64 / 65（98%） |
| 540P | 65 / 65（100%） |

> 这解释了观感：**只有 1/5 的视频有 4K**，2/3 有 2K；剩下三成最高就是 1080P。
> 所以"刷十条只有两条是 4K"是正常的，不是补丁没生效。

## 四、客户端内部标识对照（补丁用得到）

抖音客户端不用档位名，用的是 `definition` 数字 + `gearClarity` 字符串码：

| 画质 | `definition` | `gearClarity` | 菜单文案 | 实测解码 |
|---|---|---|---|---|
| 4K | **-2** | `20` | 超清 4K | 2160×3840 / 3840×2160 |
| 2K | **-1** | `10` | 超清 2K | 1440×2582 / 2560×1440 |
| 1080P | **1** | `5` | 高清 1080P | 1080×1920 / 1920×1080 |
| 720P | **2** | — | 高清 720P | 720×1280 / 1280×720 |
| 540P | **3** | — | 高清 540P | 576×1032 |

> `definition` 越小画质越高（-2 < -1 < 1 < 2 < 3），这是补丁里"取列表最高档 = 取最小 definition"的依据。

## 六、对补丁的意义

1. **补丁只能在该视频的档位表里挑**。表里最高是 1080P，就永远到不了 2K/4K——这不是补丁的 bug。
2. 实测发现：客户端**有时拿到的档位表比接口返回的少**（例如接口给了 14 档含 1440p，
   但播放器手里只有 `720_2_1/720_3_1/540_3_1` 三档）。这是客户端自己的裁剪，
   与 `channel`/`aid`/主机名/编码族都无关（这些假设都逐一验证并排除了）。
3. 想突破这个裁剪，只有两条路：注入档位（改客户端播放器列表）或换源播放（自己取直链替换播放源）。
