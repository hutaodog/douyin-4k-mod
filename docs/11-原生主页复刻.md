# 11-原生主页复刻（A 方案第一刀）

> A 方案：不再拿 CSS 去套桌面网页，而是**用原生控件把页面重画一遍**，数据从网页上下文里取。
> 本轮先落地两个最"长草"的页面：**作者主页 / 个人主页**。
>
> 设备：Redmi K40（Android 13）　｜　APK：`mobile-app/build/Douyin4K.apk`（62 KB）
> 截图：`mobile-app/shots/63-profile.png`（个人主页）、`66-author.png`（作者主页）

## 二、数据怎么来的（关键设计）

抖音的 web 接口要登录态 + 一堆站内参数（`a_bogus`/`msToken` 之类），在 native 里拼 `HttpURLConnection` 十有八九被拒。
实测发现：**在页面上下文里 `fetch` 同源接口，什么都不用签，直接 200**。

```
ProfileActivity（原生 UI）
   │  WebData.requestProfile(secUid)
   ▼
主 WebView.evaluateJavascript("window.dy4kApi.profile('<secUid>')")
   │  页面里：fetch('/aweme/v1/web/user/profile/other/?…', {credentials:'include'})
   ▼
回调 dy4kNative.profileData(json)  →  WebData.deliver(json)  →  ProfileActivity 渲染
```

用到的两个接口（都是实测可用、无需签名）：

```
GET /aweme/v1/web/user/profile/self/?device_platform=webapp&aid=6383
GET /aweme/v1/web/user/profile/other/?device_platform=webapp&aid=6383&sec_user_id=<sec_uid>
GET /aweme/v1/web/aweme/post/?device_platform=webapp&aid=6383&sec_user_id=<sec_uid>&max_cursor=0&count=24
```

> 顺带确认：`/aweme/v1/web/aweme/detail/?aweme_id=…` 在页面上下文里也能 200，但返回的 `video.bit_rate`
> 是**空的**（网页自己那次请求才带全档位），所以"从主页网格直接原生播 4K"这条路暂时走不通，
> 网格点击改成跳网页详情页（那里有我们的「原生 4K」按钮）。

图片是另一回事：抖音图床（`p3-pc-sign.douyinpic.com` 等）要求 `Referer: https://www.douyin.com/`，
`ImageView` 带不了头，于是写了 `ImgLoader`（自己的 `HttpURLConnection` + Referer + UA + 内存 LRU + 降采样）。

## 三、新增/改动的文件

```
mobile-app/java/com/dypc4k/douyink4/
├─ ProfileActivity.java   原生主页（顶栏 / 资料区 / 关注·粉丝·获赞 / 作品·喜欢 / 3 列网格）
├─ WebData.java           把主 WebView 当数据代理（页面 fetch → 回调 native）
├─ ImgLoader.java         带 Referer 的图片加载器（LRU + 线程池 + 降采样）
└─ RatioImageView.java    3:4 封面容器
mobile-app/java/com/dypc4k/douyink4/MainActivity.java
    + JS 桥 openProfile / profileData / postsData
    + startActivityForResult(ProfileActivity) → 回调里 loadUrl(/video/<id>)
mobile-web/douyin-4k.user.js
    + window.dy4kApi.profile()/posts()（页面上下文里 fetch 同源接口）
    + installUserLinkInterceptor()（capture 拦 a[href*="/user/"] → 原生主页）
    + 「我的」底部导航直接开原生主页；浮层头像走 gotoAuthor()
```

## 四、还没做的（下一刀）

| 事项 | 说明 |
|---|---|
| 关注 / 私信 / 编辑资料 | 现在是 toast 占位；写接口同样要签名，得复用页面上下文去点网页按钮 |
| 分页 | 只取了第一页 24 条；`max_cursor` 已经拿到，滚动加载还没接 |
| 「喜欢」分栏 | 只显示数量，没取列表（接口 `…/aweme/favorite/`） |
| 原生 feed | 现在 feed 仍是网页版；A 方案下一步是把 feed 也原生化（原生播放器 + 自绘浮层） |
| 原生接 4K | 主页网格点进去是网页详情页；但**卡点已解**：`dy4kApi.detail(awemeId)` 在页面上下文里能拿到完整 `bit_rate`（实测 27 档，最高 3840×2160 h265），配 `dy4kApi.bestMp4(aweme)` 取档后可直接调原生播放器 |

## 五、复现

```powershell
cd F:\ddddddd\douyin-4k-mod
npm run app:install                                     # 构建+安装+启动
node mobile-app/tools/device.mjs eval "dy4kApi.profile('')"   # 在页面里直接看资料 JSON
node mobile-app/tools/device.mjs log dy4k                    # 看 openProfile / profile -> open video
```

真机验收路径：
1. 打开 App（推荐流）→ 点右侧头像 → 应弹出原生作者页（顶栏是作者昵称）；
2. 点底部「我的」→ 应弹出原生个人主页；
3. 原生主页里点任意作品封面 → 回到网页详情页，可点「原生 4K」；
4. 返回键：原生页 → 回推荐流。
