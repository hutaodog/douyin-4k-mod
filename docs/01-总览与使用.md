## 二、装 / 卸 / 换档

```bat
:: 安装（默认 4k，推荐配置）
powershell -ExecutionPolicy Bypass -File install-preload.ps1

:: 换档位：4khdr / 4k / 2k / 1080p
powershell -ExecutionPolicy Bypass -File install-preload.ps1 -Target 2k

:: 带诊断探针（排查用，会多写 dypc4k-diag.log）
powershell -ExecutionPolicy Bypass -File install-preload.ps1 -WithDiag

:: 关闭 AB 改写（会退回"看 8 秒后掉档"的状态，仅用于对照）
powershell -ExecutionPolicy Bypass -File install-preload.ps1 -NoAbPatch

:: 彻底卸载，还原到官方原版（md5 会回到 bfcb8e31…）
powershell -ExecutionPolicy Bypass -File uninstall-preload.ps1
```

安装脚本的三个硬要求（都已内置）：

1. **必须先完全退出抖音**（否则文件被占用，或旧进程继续用旧代码）；
2. **幂等**：重复安装会先剥掉旧补丁块，不会叠加；
3. **自动备份**：`preload.js.dypc4k.bak`，只备份一次，永远保留最原始版本。
