# 17-PC 版「一键 4K」补丁包（可分发）

> 目标：把一个双击就能用的工具发给别人，对方不用装 Node、不用敲命令，
> 双击 → 自动定位抖音 → 关闭 → 备份 → 注入 → 校验 → 重新打开，全程十几秒。

产物：仓库根目录 **`抖音4K一键补丁.zip`**（21 KB，5 个文件）

---

## 一、包里有什么

```
抖音4K一键补丁/
├─ 一键开启4K.cmd        ← 对方双击这个
├─ 恢复原版.cmd          ← 想还原就双击这个
├─ dypc4k.ps1            ← 安装/还原/查看状态的全部逻辑
├─ preload-snippet.js    ← 真正注入的脚本（45 KB）
└─ 使用说明.txt           ← 给非技术用户看的说明 + 排错
```

## 二、安装器做了哪些事（`dypc4k.ps1`）

| 步骤 | 做法 |
|---|---|
| **定位安装目录** | 依次尝试：命令行参数 → 注册表 `Uninstall\*` 的 `InstallLocation`（匹配"抖音/douyin"）→ 正在运行的 `douyin.exe` 路径 → 常见路径（`D:\软件\抖音\douyin`、`Program Files`、`LOCALAPPDATA`）。找到后按**版本号目录倒序**取最新，并确认 `resources\app.asar.unpacked\preload.js` 存在 |
| **关闭客户端** | 抖音是单实例的，文件被占用时改不了。检测到在跑就问一句，回车即关（先 `douyin_tray` 再 `douyin`），关完再校验一次进程 |
| **备份** | 第一次写入前把原文件存成 `preload.js.dypc4k.bak`，**只备份一次**，保证任何情况下都能还原到最原始版本 |
| **注入** | 先把自己旧的补丁块（含探针）用正则剥掉 → 变成幂等；再追加新的块，并把 `TARGET / FIGHT / LOCK_CODEC / REFUSE / AB_PATCH` 这几个开关写死成推荐值 |
| **校验** | 写回后重新读文件，确认 begin/end 标记各一处、打印写入前后 md5；失败会明确报"被拦截（杀软？）" |
| **还原** | `-Mode restore` 直接拿 `.bak` 覆盖回去，并确认标记已消失 |
| **权限** | 写不进去时自动 `Start-Process -Verb RunAs` 弹 UAC 重新跑一遍；已经提权过就直接报错，不循环弹窗 |
| **状态** | `-Mode status` 只打印：安装目录 / 版本 / 是否已打补丁 / 有无备份 / 目标档位 |

编码上有两个坑已经处理：`.ps1` 和 `.txt` 都存成 **UTF-8 带 BOM**（否则 PowerShell 5.1 / 老记事本会把中文读成乱码），`.cmd` 里保持纯 ASCII。

补充校验：

- `node --check preload.js` → **语法 OK**（注入后仍是合法 JS，不会把客户端搞到启动不了）
- `==== dypc4k begin ====` / `end` 各 **1** 处（幂等，重复双击不会叠加）
- `node test-payload.mjs` → 全部通过（档位映射、非抖音域不生效、子域生效等）
- 把 zip 解压到临时目录再跑一遍 `apply` → 同样成功（确认相对路径没问题）

## 四、发给别人时的注意事项

1. **让对方先解压再双击**，不要在压缩包里直接点（临时目录里跑会找不到同目录的 `preload-snippet.js`）。
2. 客户装修到 `Program Files` 时第一次会弹 UAC，让 TA 点"是"。
3. 抖音**自动更新会覆盖** `preload.js`，4K 失效就重新双击一次——说明书里写了。
4. 杀软可能提示"修改其他程序文件"，说明书里给了应对（可以只让人工检查 `preload-snippet.js`）。
5. 不要把 `.zip` 改名成 `.exe` 之类的花活，保持原样最省事。

## 五、如果以后想换策略

`dypc4k.ps1` 顶部就是参数，命令行可以直接调：

```powershell
# 装成 4K HDR
powershell -ExecutionPolicy Bypass -File .\dypc4k.ps1 -Mode apply -Target 4khdr

# 指定安装目录（自动定位失败时）
powershell -ExecutionPolicy Bypass -File .\dypc4k.ps1 -Mode apply -InstallRoot "E:\apps\douyin"

# 只查状态
powershell -ExecutionPolicy Bypass -File .\dypc4k.ps1 -Mode status
```

要不要把「原生 4K 播放器」那套（MediaPlayer 硬解）也做成 PC 版的可选项，是另一个话题——
PC 客户端本身就是个 Chromium，直接改清晰度档位就够了。
