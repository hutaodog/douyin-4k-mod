# 实现篇：右键「视频详情」实时面板

> 代码同样在 `preload-snippet.js` 的 `INFO_FN` 里，通过 `webFrame.executeJavaScript` 注入页面主世界。
> 效果：视频/图文上右键 → 菜单底部多一项 → 点开为常驻面板，**每 700ms 自动刷新、切视频自动跟随**。

## 二、难点：怎么稳定找到那个菜单容器

第一次我按"`position:fixed` + 末尾 400 个 div + 正则匹配菜单文字"找，**失败**（你截图里没有那一项）。
原因是：菜单容器未必 fixed、DOM 位置不固定、React 还在异步渲染。

改成 **打分法 + 多次重试**：

```js
var LABELS = ['清屏','评论','赞','进入作者主页','推荐朋友','分享','不感兴趣','举报','独立窗口','进入详情页'];

function scoreMenu(el) {
  var txt = el.innerText || '';
  if (!txt || txt.length > 500) return 0;
  var hits = 0;
  for (var i = 0; i < LABELS.length; i++) if (txt.indexOf(LABELS[i]) >= 0) hits++;
  if (hits < 3) return 0;                        // 至少命中 3 个条目才算菜单
  var r = el.getBoundingClientRect();
  if (!r || r.width < 60 || r.width > 520 || r.height < 60 || r.height > 900) return 0;  // 尺寸合理
  return hits;
}

function findMenu() {
  var best = null, bestScore = 0;
  var all = document.querySelectorAll('div,ul,section');
  for (var i = 0; i < all.length; i++) {
    var s = scoreMenu(all[i]);
    if (s > bestScore) { bestScore = s; best = all[i]; }
  }
  if (best) {                                    // 再往"最小的那个子容器"收一层，避免插到外层留白里
    var kids = best.querySelectorAll('div,ul');
    for (var j = 0; j < kids.length; j++) {
      var s2 = scoreMenu(kids[j]);
      if (s2 >= bestScore) { best = kids[j]; bestScore = s2; }
    }
  }
  return best;
}

document.addEventListener('contextmenu', function () {
  for (var i = 0; i < 10; i++)
    (function (n) { setTimeout(function () { injectMenuItem(n); }, 40 * n + 40); })(i);   // 10 次 × 40ms
}, true);
```

插入的条目复刻原菜单样式（12px 字号 / 22px 行高 / 深色底 hover）：

```js
var item = document.createElement('div');
item.setAttribute('data-dypc4k-info', '1');
item.textContent = '视频详情（码率 / 分辨率 / 帧率）';
item.style.cssText = 'padding:4px 14px;cursor:pointer;font-size:12px;line-height:22px;color:#eaeaea;' +
                     'border-top:1px solid rgba(255,255,255,.10);margin-top:3px;white-space:nowrap;';
item.onclick = function (ev) { ev.stopPropagation(); showPanel(); };
findMenu().appendChild(item);
```

**兜底快捷键**（菜单结构变了也不至于没法用）：

```js
document.addEventListener('keydown', function (ev) {
  if (ev.altKey && (ev.key === 'i' || ev.key === 'I')) { ev.preventDefault(); showPanel(); }
}, true);
```

## 三、面板：常驻 + 实时

### 3.1 结构

```
┌ ● 实时                      ✕ ┐   ← 标题栏可拖动
│ 分辨率        2160 × 3840      │
│ 清晰度        adapt_lowest_4_1 @-2 │
│ 视频码率(声明) 12.34 Mbps       │
│ 实测码率(实时) 11.87 Mbps  ← 绿 │
│ 实测帧率(实时) 29.8 fps    ← 绿 │
│ 编码          h264 / DASH      │
│ 音频码率      128 kbps         │
│ 可选挡位      …@-2 …@-1 …@1    │
│ 已解码帧/丢帧  1234 / 0        │
│ 缓冲余量      8.3 s            │
│ 播放进度      12.4 / 30.0 s    │
│ 累计下载(媒体) 18.2 MB         │
└──────────────────────────────┘
```

每 700ms 重算一次并重绘（`setInterval(renderLive, 700)`），**切视频时自动换数据**：

```js
function activeVideo() {
  var vs = [].slice.call(document.querySelectorAll('video'));
  for (var i = 0; i < vs.length; i++) if (!vs[i].paused && vs[i].videoWidth) return vs[i];  // 正在播的
  for (var j = 0; j < vs.length; j++) if (vs[j].videoWidth) return vs[j];
  return vs[0] || null;
}
```

播放器实例则通过"哪个 player 的 video/root 包含这个元素"来对齐：

```js
for (var i = 0; i < players.length; i++) {
  if (pp.video === v || (pp.root && pp.root.contains(v))) { p = pp; break; }
}
```

### 3.2 实测帧率：`requestVideoFrameCallback` 滚动 1 秒窗口

```js
function watchFps(v) {
  if (fpsState.v === v) return;                   // 已在该元素上测
  fpsState = { v: v, n: 0, t0: 0, fps: null };
  var step = function (now) {
    if (fpsState.v !== v) return;                 // 元素换了就停
    if (!v.paused) {
      if (!fpsState.t0) fpsState.t0 = now;
      fpsState.n++;
      if (now - fpsState.t0 >= 1000) {
        fpsState.fps = (fpsState.n * 1000 / (now - fpsState.t0)).toFixed(1);
        fpsState.n = 0; fpsState.t0 = now;
      }
    }
    v.requestVideoFrameCallback(step);
  };
  v.requestVideoFrameCallback(step);
}
```

> 比 `getVideoPlaybackQuality().totalVideoFrames` 差分更准（后者粒度粗，且受丢帧影响）。

### 3.3 实测码率：Resource Timing 两次采样差

```js
function mediaBytes() {
  var s = 0;
  performance.getEntriesByType('resource').forEach(function (e) {
    if (/douyinvod|bytecdn|tos-cn|video\/tos|mime_type=video|mime_type=audio/i.test(e.name))
      s += e.transferSize || 0;                   // 只统计媒体域名/媒体参数
  });
  return s;
}

// 每次 tick：
var b = mediaBytes(), now = performance.now();
if (bwState.t) {
  var dt = (now - bwState.t) / 1000;
  if (dt > 0.1 && b >= bwState.bytes) bwState.mbps = ((b - bwState.bytes) * 8 / dt / 1e6).toFixed(2);
}
bwState.bytes = b; bwState.t = now;
```

这是**链路真实吞吐**（含音频分段），会和"声明码率"有差异，属于正常。

### 3.4 数据来源对照

| 显示项 | 来源 |
|---|---|
| 分辨率 | `video.videoWidth × videoHeight`（真实解码尺寸） |
| 码流分辨率 | `player.curDefinition.width/height` |
| 清晰度挡位 | `player.curDefinition.gearName` + `.definition` |
| 视频码率(声明) | `.realBitrate \|\| .bitrate` |
| 实测码率/帧率 | 上面两段实时算法（绿色标注） |
| 编码 | `.codecType` / `.vtype` |
| 音频码率/编码 | `player.config.definition.list` 里 `mediaType==='audio'` 的条目 |
| 可选挡位 | 同 list 全部条目 `gearName@definition` |
| 已解码帧/丢帧 | `video.getVideoPlaybackQuality()` |
| 缓冲余量 | `buffered.end(last) - currentTime` |
| 播放进度/暂停 | `currentTime` / `duration` / `paused` |
| 累计下载 | Resource Timing 累计 `transferSize` |

## 四、验证方法

1. 焦点在视频上 → 按 `Alt+I`（不依赖菜单，最稳）
2. 面板出现后**让视频播着**：实测码率/帧率每秒跳动
3. **滑动切换视频**：面板数据自动换成新视频的（标题栏会短暂显示「已切换视频」）
4. 拖动标题栏 → 面板可移动；点 ✕ → 关闭

排查：`%APPDATA%\douyin\dypc4k-lock.log` 里会写

```
info   info hook installed (菜单注入 + Alt+I 兜底)
info   menu item injected into DIV.xxxxx     ← 插进去了
info   menu not found after retries          ← 没找到容器（换页面结构了）
info   live panel opened
```

## 五、已知限制

| 限制 | 说明 |
|---|---|
| 菜单文字变了要更新 `LABELS` | 客户端改版后菜单文案变化，把新条目加进 `LABELS` 即可 |
| 图文（无视频） | 面板会显示"没找到正在播放的视频"，其余字段为空 |
| 弹幕/直播页 | 可能没有 `xgplayer` 容器，播放器相关字段为空，但分辨率/帧率仍可用 |
| `transferSize` 被策略屏蔽时 | 实测码率显示"测量中…"，可改用 `buffered` 增长速度反推 |
