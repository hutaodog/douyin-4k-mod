# 实现篇：把 4K 固定住（注入点选择 + 四层机制 + 代码）

> 文件：`preload-snippet.js`（安装时被追加到客户端 `preload.js` 末尾）
> 全部运行在 **网页层**：一段在隔离世界（preload），一段注入页面主世界（main world）

---

## 一、为什么是 preload，而不是 CDP / 改 asar

| 方案 | 实测结果 |
|---|---|
| `douyin.exe --remote-debugging-port=92258` | 主进程命令行确实带上了开关，但 **端口从不 listen**；`--inspect` 同样不开 → 客户端加固，CDP 不可用 |
| 改 `app.asar` | 网页层代码不在 asar 里（它是远程 `www.douyin.com`），改了也没用 |
| MITM 改 CDN 的 JS chunk | 要装根证书 + 赌没做证书固定，收益低、维护成本高 |
| **改 `app.asar.unpacked/preload.js`** | ✅ 它是 Electron 真正的网页 preload（41KB，注入 `TTE_ENV` + CANS JSBridge），改动即生效，且**升级前一直有效** |

用探针确认过 preload 的作用范围（日志）：

```
file:///…/pages/firstLoading/index.html   ← 首屏
https://www.douyin.com/                    ← 主页面
https://live.douyin.com/preload-living     ← 直播
（每帧都会跑，sessionStorage/localStorage 在主页面可用）
```

## 二、四层机制（按必要性排序）

```
第 1 层  MANUAL_SWITCH 写入 + 心跳          ← 必需：让播放器"以为"你手选了 4K
第 2 层  AB 响应改写（关掉自动重选/降档）    ← 必需：真正止血的一层
第 3 层  播放器锁（关 ABR + 钉档位）         ← 辅助：兜底，防首帧起在低档
第 4 层  编码能力改判 / 列表回填 / 拦 changeDefinition ← 默认关闭：实测压不住，且有副作用
```

## 三、第 1 层：写入 `MANUAL_SWITCH`（并学会客户端的真实结构）

### 3.1 值长什么样

```js
// 4K 档（来自 chunk player-Clarity 的 gear 表）
{ "done":1, "gearType":-2, "gearClarity":"20", "gearName":"超清 4K", "qualityType":1 }
```

### 3.2 先学结构，再覆盖（避免"合成值"和客户端字段对不上）

在 **主世界** 装钩子，把客户端自己写过的值原样存下来当模板：

```js
var MAIN_HOOK = '(' + function () {
  var proto = window.Storage && window.Storage.prototype;
  var set = proto.setItem, rem = proto.removeItem;
  proto.setItem = function (k, v) {
    var r = set.apply(this, arguments);
    if (String(k) === 'MANUAL_SWITCH') localStorage.setItem('__DYPC4K_RAW__', String(v));
    return r;
  };
  proto.removeItem = function (k) {
    var r = rem.apply(this, arguments);
    if (String(k) === 'MANUAL_SWITCH') window.postMessage({ __dypc4k: 2, op: 'remove' }, '*');
    return r;
  };
}.toString() + ')()';
require('electron').webFrame.executeJavaScript(MAIN_HOOK);
```

> `webFrame.executeJavaScript` 是**主世界**执行（客户端自己的 preload 也用这招派发 JSBridge 事件），
> 所以能拿到客户端视角；而 preload 本体在隔离世界，碰不到页面的 `Storage.prototype`。

### 3.3 模板 + 覆盖

```js
function want() {
  var tpl = null;
  try { tpl = JSON.parse(localStorage.getItem('__DYPC4K_RAW__') || 'null'); } catch (e) {}
  var o = {};
  if (tpl && typeof tpl === 'object') for (var k in tpl) o[k] = tpl[k];   // 保留 clarityReal 等字段
  o.done = 1;
  o.gearType = -2; o.gearClarity = '20'; o.gearName = '超清 4K';
  if (!(tpl && String(tpl.gearClarity) === '20' && typeof tpl.qualityType === 'number')) o.qualityType = 1;
  return JSON.stringify(o);
}
```

### 3.4 心跳（对抗客户端的 mount 时清除）

```js
function tick() {
  var v = want(), c = sessionStorage.getItem('MANUAL_SWITCH');
  if (c === v) return;
  var keep = false;
  try { var o = JSON.parse(c); keep = o && o.gearType === -2 && String(o.gearClarity) === '20'; } catch (e) {}
  if (!keep) sessionStorage.setItem('MANUAL_SWITCH', v);
}
tick();
[0,30,80,160,320,600,1000,1600].forEach(ms => setTimeout(tick, ms));  // 启动期加密
setInterval(tick, 400);
```

> 只写"缺失/被改回 auto"的情况，不跟客户端的"手动选择"抢。

## 四、第 2 层：改写 AB 响应（关键一层）

### 4.1 拦截点

客户端从两个地方拿 AB 参数，都要拦：

```
XHR  https://www.douyin.com/service/2/abtest_config/         ← 实测主要走这条
XHR  https://www-hj.douyin.com/aweme/v1/web/mobile/ab/params/
页面 window.TTE_ENV.layoutInitialProps.allAbParams           ← preload 预置的那份
```

### 4.2 代码（XHR 侧，覆盖 `responseText` / `response` 的 getter）

```js
var AB_URL = /ab\/params|mobile\/ab|abtest/i;

var xopen = XMLHttpRequest.prototype.open;
XMLHttpRequest.prototype.open = function (m, u) { this.__dypc4kUrl = String(u || ''); return xopen.apply(this, arguments); };

var descText = Object.getOwnPropertyDescriptor(XMLHttpRequest.prototype, 'responseText');
Object.defineProperty(XMLHttpRequest.prototype, 'responseText', {
  configurable: true,
  get: function () {
    var t = descText.get.call(this);
    try {
      if (this.__dypc4kUrl && AB_URL.test(this.__dypc4kUrl) && this.readyState === 4 && t) {
        var j = JSON.parse(t); var n = patchABObj(j, 0);
        if (n) post('abpatch', 'xhr changed=' + n + ' [' + stat.keys.join(',') + ']');
        return JSON.stringify(j);
      }
    } catch (e) {}
    return t;
  }
});
```

`fetch` 侧用 `new Response(JSON.stringify(j), {...})` 包一层（代码同构）。

### 4.3 到底改哪几个键

```js
var AB_OFF = ['auto_clarity_reselect', 'switch_clarity_timing', 'smooth_switch_clarity'];

function patchABObj(o, depth) {
  if (!o || typeof o !== 'object' || depth > 6) return 0;
  var n = 0;
  for (var k in o) {
    var v = o[k];
    if (AB_OFF.indexOf(k) >= 0 && v !== 0) { o[k] = 0; n++; }
    else if (k === 'maxDownSwitchLevel' && Number(v) !== 0) { o[k] = 0; n++; }
    else if ((k === 'rebufferDegrade' || k === 'safeRebufferDegrade') && Number(v) !== 0) { o[k] = 0; n++; }
    else if (v && typeof v === 'object' && patchABObj(v, depth + 1)) n++;
  }
  return n;
}
```

**只改这 5 个键**（踩坑记录见 `05-避坑指南.md` 第 10 条：曾把 `use_h266_client`、`degradeBitrateFactors` 也改掉，导致部分视频只剩 720P/540P）。

## 五、第 3 层：播放器锁（兜底）

### 5.1 怎么拿到播放器实例

客户端禁用了调试端口，所以只能在主世界里"找"：

```js
function allPlayers() {
  var ps = [];
  // A) window / DOM 上的播放器实例（xgplayer 常挂在容器元素上）
  Object.keys(window).forEach(function (k) {
    if (/webpack|performance|chrome|webkit/i.test(k)) return;
    var v = window[k];
    if (v && typeof v === 'object' && typeof v.changeDefinition === 'function' && v.config) ps.push(v);
  });
  document.querySelectorAll('[class*="xgplayer"], [class*="player"]').forEach(function (el) {
    Object.getOwnPropertyNames(el).forEach(function (n) {
      var o = el[n];
      if (o && typeof o === 'object' && typeof o.changeDefinition === 'function' && o.config) ps.push(o);
    });
  });
  // B) webpack 模块缓存里的 getAllPlayer 注册表（本版本 req.c 为空，未生效，保留）
  return uniq(ps);
}
```

### 5.2 关掉 ABR + 钉档位

```js
if (c.needAutoBitrate !== false) {
  c.needAutoBitrate = false;
  c.autoBitrateOpts = { isPlayAutoDefi: false, isOpenAutoDefi: false };
}
if (entry && cur !== -2) player.changeDefinition(entry, player.curDefinition);
```

> 实测：AB 改写生效后这一层几乎不需要动作（`revert` 只在起播瞬间触发一次）。

### 5.3 为什么没有用"拦 changeDefinition + 回填列表"

代码里保留（`FIGHT = true` 才启用），但**默认关闭**，理由见避坑指南第 7、8 条：
客户端绕开 API 直接换流，回填反而造成"4K→重载→4K"的拉锯。

## 六、第 4 层：实验性开关（默认关闭）

| 开关 | 做什么 | 为什么不默认开 |
|---|---|---|
| `REFUSE = 'vvc' / 'vvc-all'` | 改判 `MediaSource.isTypeSupported` / `canPlayType` / `mediaCapabilities`，让客户端以为不支持某些编码 | `vvc-all` 会把 HEVC 也封掉，**而 4K 就是 HEVC**，结果只剩 1080P |
| `LOCK_CODEC = 'h264'` | 钉住 `config.codecType` | 单独用无效（降档不走这条） |
| `FIGHT = true` | 抽走 4K 项就塞回去 + 拦降档调用 | 客户端绕开 API，拦不住，只会增加重载 |

## 七、安装脚本做了什么（`install-preload.ps1`）

```powershell
# 1) 定位版本目录 + preload.js
$Preload = Join-Path $InstallRoot "$Version\resources\app.asar.unpacked\preload.js"

# 2) 必须在客户端退出状态
if ((Get-Process -Name douyin, douyin_tray -ErrorAction SilentlyContinue) -and -not $AllowRunning) { throw '抖音正在运行' }

# 3) 只备份一次（永远保留官方原始文件）
if (-not (Test-Path $Backup)) { Copy-Item $Preload $Backup }

# 4) 幂等：先剥掉旧补丁块（含可选探针块）
$content = [regex]::Replace($content, '(?s)\r?\n?/\* ==== dypc4k begin ==== \*/.*?/\* ==== dypc4k end ==== \*/', '')

# 5) 按参数替换片段里的常量（TARGET / FIGHT / LOCK_CODEC / REFUSE / AB_PATCH）
$snippet = $snippet -replace "var TARGET = '[^']+';", "var TARGET = '$Target';"
$snippet = $snippet -replace "var AB_PATCH = (true|false);", "var AB_PATCH = $(if ($NoAbPatch) {'false'} else {'true'});"

# 6) 追加并写回（UTF-8 无 BOM，PS 5.1 也不会乱码）
[System.IO.File]::WriteAllText($Preload, $content.TrimEnd() + "`r`n`r`n" + $append, $utf8)
```

回滚脚本就是"用 `.dypc4k.bak` 覆盖回来"，实测 md5 回到官方原值 `bfcb8e31…`。

## 八、会话级容错

| 场景 | 处理 |
|---|---|
| 页面刷新 / 切换页面 | preload 每帧重新执行，自动重装所有钩子 |
| 客户端升级覆盖 `preload.js` | md5 变化 → 重跑一次 `install-preload.ps1` |
| 你手动切到 1080P | 心跳只在"缺失/auto"时补写，不会跟你的手动选择抢 |
| 想彻底停用 | `uninstall-preload.ps1` 或把 `AB_PATCH` 改 false 重装 |
