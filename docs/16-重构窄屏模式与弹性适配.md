# 16-重构：统一窄屏模式 + 弹性适配

> 上一版把页面按站点自己的 786px 排版再缩 0.5，字小、上下大片黑边，比最初还丑。
> 这轮按你的要求重做：**统一压到设备宽度（393）**，站点走它的手机版分支，然后我们把写死的 px 改成百分比。

---

## 一、重构后的三条规则

1. **viewport 一律 `initial-scale=1`**（App 拦截 HTML 时统一改写）。
   → 站点不再按 786 排版，而是走手机版单列布局，字和间距都是正常手机尺寸。
2. **我们自己的 UI 不再补偿**（`--dy4k-k` 恒为 1），因为 scale=1。
3. **弹性适配**：站点里写死的宽度全部改成百分比：

```css
html, body { width:100% !important; max-width:100vw !important; overflow-x:hidden !important; }
[class*="route-scroll-container"], [class*="parent-route-container"] { width:100% !important; min-width:0 !important; }
#douyin-right-container { width:100% !important; left:0 !important; margin:0 !important; }
[class*="playerContainer"], [class*="xg-video-container"] { width:100% !important; }
[class*="swiper-slide"], [class*="swiper-wrapper"] { width:100% !important; }
```

另外两处针对性处理：

- **关注/朋友页**：站点排的是「左栏 + 视频 + 右栏」三栏桌面布局。左栏藏掉后布局仍占着它的宽度（208px），
  所以给左栏的父容器加 `margin-left:-208px; width:calc(100% + 208px)`，再把播放器及其上 3 层容器宽度设成 100%。
- **弹幕**：算出视频真实画面区域（扣掉 letterbox），把弹幕容器裁到「画面内、上 55%」，字号 13px。

## 三、这轮踩的坑（教训）

**锁屏会让所有设备测试结果失真**：`mWakefulness=Asleep` 时截图全黑、`document.querySelector('video')` 为空，
我因此误判"是 CSS 把播放器搞坏了"，白改三轮。

固定流程：
```powershell
adb -s 7b0137b5 shell dumpsys power | Select-String mWakefulness     # 必须 Awake
adb -s 7b0137b5 shell input keyevent KEYCODE_WAKEUP                  # 不是就点亮
adb -s 7b0137b5 shell input swipe 540 1900 540 500 200              # 上滑解锁
```
